# AZ-104 Azure Administrator Labs

This repository contains my hands-on lab exercises based on the official Microsoft AZ-104 training labs.

## Purpose
To build practical experience in Microsoft Azure by completing structured labs covering identity, networking, compute, storage, security, and governance.

## Labs included

1. Entra ID identities
2. Subscriptions and RBAC
3. Azure Policy governance
4. ARM templates
5. Virtual networking
6. Inter-site connectivity
7. Traffic management
8. Storage management
9. Virtual machines
10. Web apps and containers
11. Data protection
12. Monitoring

## Goal
To move from theoretical Azure knowledge (AZ-104 exam level) to practical cloud engineering skills through hands-on deployment and configuration.

## Technologies
- Microsoft Azure
- Microsoft Entra ID
- ARM templates (and later Bicep/Terraform)
- Networking (VNets, NSGs, Load Balancers)
- Compute (VMs, App Services, Containers)
- Monitoring & Security
