# Lab 02b - Manage Governance via Azure Policy

## What I did
- Created and assigned Azure resource tags
- Applied Azure Policy to enforce mandatory tags
- Tested policy enforcement on new resources
- Configured automatic tag inheritance from Resource Groups
- Created remediation tasks for non-compliant resources
- Configured and tested Azure Resource Locks

## What I learned
- How Azure Policy enforces governance and compliance
- Importance of tagging for cost management and resource organization
- Difference between deny and modify policy effects
- How remediation tasks update existing resources
- How Resource Locks protect Azure resources from accidental deletion

## Tools used
- Azure Portal
- Azure Policy
- Azure Resource Groups
- Azure Resource Locks
- Azure Storage Accounts

## Context
This lab is part of the AZ-104 Azure Administrator training series focused on governance, compliance, and resource management in Microsoft Azure.
