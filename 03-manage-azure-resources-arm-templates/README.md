# Lab 03 - Manage Azure Resources using ARM Templates and Bicep

## What I did
- Created a managed disk in Azure
- Exported an ARM template
- Modified and redeployed ARM templates
- Deployed templates using Azure PowerShell
- Deployed templates using Azure CLI
- Created and deployed a Bicep template

## What I learned
- Infrastructure as Code (IaC) fundamentals
- Difference between ARM templates and Bicep
- Parameterized deployments
- Azure deployment automation
- Using Cloud Shell for infrastructure deployments

## Tools used
- Azure Portal
- Azure Cloud Shell
- Azure CLI
- Azure PowerShell
- ARM Templates
- Bicep

## Context
This lab is part of the AZ-104 Azure Administrator learning path focused on Infrastructure as Code and deployment automation in Microsoft Azure.
