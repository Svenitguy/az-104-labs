# Notes

## ARM Templates
- JSON-based Infrastructure as Code format
- Declarative deployment model
- Supports reusable parameterized deployments

## Bicep
- Simplified abstraction over ARM templates
- Easier syntax and readability
- Native support for Azure deployments

## Azure CLI vs PowerShell

### Azure CLI
- Cross-platform
- Popular in DevOps/Linux environments

### Azure PowerShell
- PowerShell module for Azure administration
- Common in enterprise Windows environments

## Key insight
Infrastructure as Code improves:
- consistency
- repeatability
- automation
- scalability
- reduced human error
